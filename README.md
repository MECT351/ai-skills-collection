# AI Skills Collection by OpenClaw

一套纯Python标准库、零依赖的实用工具型Skill集合，适用于OpenClaw/AI Agent生态。

## Skills 列表

| Skill | 说明 |
|-------|------|
| openclaw-skill-dev-guide | OpenClaw自定义技能开发指南 - 脚手架生成、校验、调试、模板库 |
| prompt-analyzer | AI Agent提示词分析器 - 多维度评分、优化建议、标准模板 |
| web-fetch-toolkit | 网页抓取工具箱 - 单URL/批量抓取、元素提取、HTML转Markdown |
| browser-automation-generator | 浏览器自动化脚本生成器 - 登录/导航/表单/爬虫脚本生成 |
| ppt-generator | PPT幻灯片生成器 - Markdown大纲生成HTML幻灯片演示 |
| table-toolkit | 数据表格处理工具 - 统计分析、数据清洗、多表合并、格式转换 |
| doc-template-generator | 文档模板生成器 - 工作报告/项目方案/计划书/会议纪要模板 |
| pdf-text-extractor | PDF文本提取器 - 全文/指定页提取、元数据读取、关键词统计 |
| condition-monitor | 条件监控提醒器 - 网页内容监控、API状态检测、自定义条件判断 |
| daily-review | 每日状态评测日记生成器 - 日记生成、情绪分析、习惯追踪、周报汇总 |
| openclaw-health | OpenClaw健康自检器 - 配置完整性、网络连通性、渠道诊断 |
| privacy-guard | 主人隐私卫士 - PII扫描（手机号/身份证/邮箱/API Key）、一键脱敏 |

## 特性

- ✅ 纯Python标准库，零第三方依赖
- ✅ JSON标准化输入输出
- ✅ 每个Skill含可执行脚本 + SKILL.md
- ✅ MIT-0 License

```bash
npx skills add MECT351/ai-skills-collection
```
